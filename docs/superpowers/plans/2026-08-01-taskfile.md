# Common Taskfile Commands Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add discoverable development tasks and a command that packages and installs the current FoundryScript extension source into standard Visual Studio Code.

**Architecture:** A single root `Taskfile.yml` delegates to the repository's existing npm scripts. Packaging writes a stable ignored artifact at `dist/foundryscript.vsix`, and installation depends on that package before invoking the standard `code` CLI.

**Tech Stack:** Task 3, npm, `@vscode/vsce`, VS Code `code` CLI

---

### Task 1: Add Common Development and Source-Install Tasks

**Files:**
- Create: `Taskfile.yml`

- [ ] **Step 1: Verify the Taskfile is absent**

Run:

```bash
task --list
```

Expected: FAIL with `task: No Taskfile found` because the requested configuration does
not exist yet.

- [ ] **Step 2: Create the Taskfile**

Create `Taskfile.yml` with this complete content:

```yaml
version: "3"

tasks:
  default:
    desc: List available tasks
    cmds:
      - task --list
    silent: true

  install-deps:
    desc: Install locked npm dependencies
    cmds:
      - npm ci

  build:
    desc: Build the extension bundle
    cmds:
      - npm run build

  watch:
    desc: Rebuild the extension as files change
    cmds:
      - npm run watch

  typecheck:
    desc: Type-check the TypeScript sources
    cmds:
      - npm run typecheck

  lint:
    desc: Lint the TypeScript sources
    cmds:
      - npm run lint

  test:
    desc: Run unit and grammar tests
    cmds:
      - npm test

  check:
    desc: Build, type-check, lint, and test the extension
    cmds:
      - task: build
      - task: typecheck
      - task: lint
      - task: test

  package:
    desc: Package the extension as an installable VSIX
    cmds:
      - npm run package -- --out dist/foundryscript.vsix

  install:
    desc: Package and install the extension from this checkout
    deps:
      - package
    cmds:
      - code --install-extension dist/foundryscript.vsix --force
```

- [ ] **Step 3: Verify task discovery**

Run:

```bash
task --list
```

Expected: PASS and list `build`, `check`, `install`, `install-deps`, `lint`, `package`,
`test`, `typecheck`, and `watch` with their descriptions.

- [ ] **Step 4: Verify command composition without mutating VS Code**

Run:

```bash
task --dry check
task --dry install
```

Expected: PASS. The `check` output contains the build, typecheck, lint, and test npm
commands. The `install` output packages to `dist/foundryscript.vsix` before showing
`code --install-extension dist/foundryscript.vsix --force`.

- [ ] **Step 5: Build the VSIX through the new task**

Run:

```bash
task package
test -f dist/foundryscript.vsix
```

Expected: PASS and create the ignored `dist/foundryscript.vsix` artifact. Do not run
`task install` during automated verification because it changes the user's local VS
Code installation.

- [ ] **Step 6: Run the repository verification suite**

Run:

```bash
npm ci
npm run build
npm run typecheck
npm run lint
npm test
```

Expected: all commands exit 0 with all unit and grammar tests passing.

- [ ] **Step 7: Check the final diff and commit**

Run:

```bash
git diff --check
git status --short
git add Taskfile.yml
git commit -m "build: add common Taskfile commands"
```

Expected: `git diff --check` exits 0; status shows only the intended Taskfile before the
commit; the commit succeeds.
